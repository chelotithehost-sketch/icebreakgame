Iffy Business is a short icebreaker where people write silly "If…" questions and answer each other's questions without seeing them. 
The mismatched pairs are the joke.
Before the game: the host opens the app link with ?mode=host, enters the PIN, and shares the normal link with the team.
Round 1, Write: each player joins with a name, presses a button to draw a random number from 1 to 999, and saves a question such as "If Mark was the president of Seychelles?". The numbers work like raffle tickets.

Round 2, Answer: the host closes writing and the app deals tickets automatically. Each player gets one ticket that isn't their own and writes an answer without seeing the question. Everyone sees a grid of numbered tiles, and the doors lock so latecomers see "wait for the next round".

Round 3, Reveal: the host opens tickets one at a time, and each shows the question with its mismatched answer. Players press 😂 on the ones they find funny.

Round 4, Winners: the tickets with the most laughs are shown as the top 3, followed by the rest.

The host never plays. They run the timer, lock or open the doors, deal the tickets, open the tickets one by one, and can skip an unsuitable one. A full run with a small team takes about 15 minutes.

How to run it:

On share.streamlit.io, click "Create app", pick this repo, and set the main file to app.py.
Under "Advanced settings → Secrets", add HOST_PIN = "your-pin". 
Without it, the PIN defaults to 1234.
Open the link a few minutes before the game, because free apps sleep when idle. 
Share the same link with everyone.
